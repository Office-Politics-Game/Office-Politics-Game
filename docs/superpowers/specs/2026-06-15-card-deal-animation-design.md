# Issue #22 發牌動畫設計

## 目標

提供獨立的開局發牌動畫展示。四張牌由牌庫依序發給下、左、上、右四位玩家，每位玩家一張；對手保留牌背，目前玩家顯示牌面。

## 元件設計

- `CardDealAnimation.vue` 是無遊戲狀態的動畫層，接受牌庫座標、玩家落點與牌卡資料，公開 `play()` 與 `cancel()`。
- `PlayerSeats.vue` 提供三位對手的牌背手牌槽及 `getHandTargetRect(playerId)`。
- `PlayerHand.vue` 提供第一張牌的置中落點 `getDealTargetRect()`，原有抽牌落點維持不變。
- `CardDealDemoView.vue` 負責展示資料、座標量測、播放鎖定、落地狀態及重播。

## 動畫與狀態

- 固定順序為下、左、上、右，相鄰牌相隔 `0.25s` 啟動，每張飛行約 `0.55s`。
- 牌背由牌庫中心抬升後沿弧線飛往玩家，最終方向為下 `0°`、左 `90°`、上 `180°`、右 `-90°`。
- 每張啟動時牌庫減一；落地時由固定手牌 UI 接管顯示。
- 播放中禁止重複觸發。重新播放會先恢復 28 張牌並清空所有手牌。
- 任一座標缺失時不播放部分序列，顯示錯誤訊息並保留可重試狀態。
- reduced-motion 模式改為依序在落點淡入，不執行長距離飛行。

## 範圍

- 展示入口為 `/card-deal-demo`，不自動接入正式開局流程。
- 不修改 `GameView.vue`、現有抽牌資料流或 `CardDrawAnimation.vue`。
- 所有新增 UI 遵循 Square UI，使用方形控制項與既有色彩 token。

## 驗收

- 一次播放後牌庫由 28 變為 24，每位玩家恰好一張牌。
- 自己顯示正面，三位對手顯示朝向各自座位的牌背。
- 播放中連點無效，重播不累加牌數。
- 支援取消、卸載清理、reduced-motion 與響應式橫向版面。
