# Office Politics 專案規範

## 執行順序

1. 先讀取 [團隊開發規範](references/team-development-standards.md)，並套用到所有專案工作。
2. 判斷任務是否涉及前端呈現或互動。
3. 若涉及 Vue 畫面、元件、CSS、Tailwind class、版面、字體、色彩、按鈕、互動狀態或 RWD，再讀取 [Square UI 視覺規範](references/square-ui-style-guide.md)。
4. 無法判定是否屬於 UI 任務時，同時讀取兩份規範。
5. 規劃、修改、審查、測試與提交前，逐項確認成果符合已載入的規範。

## 規範優先順序

- 將本 skill 內的 references 視為正式版本；Downloads 中的原始檔只作為來源資料。
- 使用者需求若與規範衝突，先指出衝突規則與影響，等待使用者明確同意後才能偏離。
- 規範檔缺失或無法讀取時，停止依賴該規範的工作並回報。
- 不因啟用本規範而主動重構既有違規程式；只處理目前任務涵蓋的範圍。

## 語言

- 專案的人類可讀說明使用繁體中文。
