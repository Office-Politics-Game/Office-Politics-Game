# 牌庫與棄牌區桌面傾斜效果設計

## 目標

讓牌庫與棄牌區看起來自然放置於遊戲桌上，並在支援滑鼠的裝置提供輕微、平滑的視角跟隨效果。

## 視覺與互動

- 兩個牌堆固定使用約 58 度的 X 軸仰角，以牌底為支點向桌面躺下。
- 牌庫預設略向左旋轉，棄牌預設略向右旋轉，避免排列過度工整。
- 兩個牌堆各自具備接觸陰影與柔和外陰影，呈現卡牌厚度和桌面距離。
- 游標在單一牌堆上移動時，只在固定仰角附近小幅改變 `rotationX`、`rotationY` 與上浮高度。
- 游標離開後，以 GSAP 平滑回到 58 度桌面仰角。
- 觸控裝置與偏好減少動態效果的使用者只顯示固定傾斜與陰影，不啟用游標跟隨。

## 實作邊界

- 修改 `src/components/game/TableCardPiles.vue`。
- 沿用現有 `GameCard.vue`，不影響手牌卡片。
- 使用 Vue 生命週期建立與清除 GSAP context、媒體查詢與事件監聽。
- 使用 Tailwind utilities 處理尺寸與版面，元件 scoped CSS 處理多層陰影和 3D 呈現。

## 驗收

- 牌庫與棄牌區具備不同的固定旋轉角度。
- 支援精準游標且未要求減少動態效果時，牌面會輕微跟隨游標。
- 離開牌面後會回復預設角度。
- 元件卸載時不殘留事件監聽或 GSAP 動畫。
- `npm test` 與 `npm run build` 通過。
