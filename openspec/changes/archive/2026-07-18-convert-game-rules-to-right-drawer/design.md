## Context

`GameRulesModal.vue` 目前以右下角小按鈕為起點並改變容器寬高。遊戲僅支援 960×540 與 1280×720 兩檔橫向畫布，且必須維持 Square UI 固定尺寸與無圓角設計。

## Goals / Non-Goals

**Goals:**

- 將入口與面板改為貼齊畫布右緣的覆蓋式抽屜。
- 動畫只作用於抽屜自身，不影響其他遊戲 UI。
- 讓規則與卡牌分頁在固定窄欄中可閱讀並可垂直捲動。
- 保留既有鍵盤操作，再加入欄外點擊關閉。

**Non-Goals:**

- 不改動 `GameStage` 牌桌配置或縮放遊戲內容。
- 不修改規則資料、圖像、API 或遊戲邏輯。
- 不支援直向版面或新增響應式斷點。

## Decisions

### 固定尺寸覆蓋式右側抽屜

抽屜以 `absolute` 貼齊既有遊戲畫布的上、右、下邊界，標準橫向寬 480px、小型橫向寬 400px，避免 viewport 尺寸單位與牌桌重排。

### 獨立裁切揭露動畫

側欄與半圓切換鈕放在同一個絕對定位容器，由容器統一執行 `translateX()`。收合時容器移動自身寬度的 100%，側欄位於畫布外，而向左凸出的半圓按鈕留在右側邊界；展開時容器回到原位。容器不參與 GameStage 排版，並建立獨立 stacking/compositing layer，確保按鈕與側欄視為同一物件、同時開始及結束動畫。

### 底部三分之一高度半圓切換鈕

同一顆切換鈕固定在距離畫布底部三分之一高度的位置。收合時貼齊畫布右緣並使用 `ChevronLeft` 呈現 `<`；展開時移至側欄左緣並使用 `ChevronRight` 呈現 `>`。按鈕外側為半圓形；這是使用者明確核准、僅限此控制鈕的 Square UI 無圓角例外，並取代標頭右上角 X。

### 欄外遮罩互動層

展開時在抽屜後方加入覆蓋畫布的深藍 `rgba(0, 19, 50, 0.62)` 遮罩按鈕層，點擊即關閉；抽屜本身位於更高層級，內部操作不會觸發欄外關閉。遮罩不執行 opacity transition，避免建立全畫面動畫合成層。

### 窄欄垂直內容流

標頭固定在抽屜頂端，開啟時優先顯示卡牌分頁。卡牌標題列下方的四欄表格填滿剩餘高度。規則頁移除「遊戲資訊」，只保留「遊戲目標」、「勝利條件」與「遊戲流程」，三個區塊等高填滿內容區。
小型橫向版的「遊戲流程」區塊採 `flex-row`，標題在左、流程圖在右；標準橫向版維持標題在上、流程圖在下。
小型橫向版的規則說明使用 8px、卡牌表格內文使用 10px，標題尺寸保持不變；標準橫向版內文維持 15px。
「遊戲目標」與「勝利條件」中的 article 使用 flex：小型橫向版採 `flex-row` 讓圖示與文字左右排列，標準橫向版採 `flex-col` 讓圖示與文字上下置中。

## Implementation Contract

- **可觀察行為：** 同一顆半圓切換鈕中心位於距離畫布底部三分之一高度；收合時貼齊右側顯示 `<`，展開時貼住側欄左緣顯示 `>`。抽屜以裁切方式揭露與隱藏。
- **動畫隔離：** 開關過程只改變絕對定位抽屜容器的 transform；GameStage 與其他 UI 的尺寸、位置及 transform 保持不變。
- **尺寸：** 小型橫向寬 400px、標準橫向寬 480px，高度貼齊畫布上下界；不得使用 `vw`、`vh`、`clamp()` 或第三組 breakpoint。
- **內容：** 規則與卡牌資料保持不變；超出高度時只捲動抽屜內容區。
- **關閉與焦點：** 關閉鍵、Escape 與透明欄外點擊均能關閉；Tab 焦點限制於抽屜內，關閉後回到入口。
- **視覺：** 所有元件維持直角，色彩與 focus ring 使用既有品牌 token，欄外層完全透明。
- **驗收：** `npm.cmd run build` 成功，並以樣式與互動檢查確認兩檔尺寸及動畫隔離。
- **範圍：** 應用程式碼只調整 `src/components/game/ui/GameRulesModal.vue`。

## Risks / Trade-offs

- [400px 欄寬使表格效果欄換行較多] → 保留完整文字並使用抽屜內捲動。
- [透明欄外層攔截展開期間牌桌操作] → 單次點擊只用於關閉，關閉後立即恢復互動。
- [contain 裁切抽屜陰影] → containment 僅套用抽屜面板並保留左側陰影在面板邊界外的必要空間。
