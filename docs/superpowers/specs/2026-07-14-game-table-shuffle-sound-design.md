# 牌桌洗牌音效設計

## 目標

當牌桌洗牌動畫正式開始時，播放一次 `src/assets/audio/game-card-shuffle.ogg`。音效必須跟隨共用的音效開關與音效音量設定，不得受背景音樂設定控制，也不得因畫面重繪額外播放。

## 架構

- 延伸 `src/composables/UseGameTableAudio.js`，集中管理兩層洗牌音效的載入、音量、裁切與安全播放。
- 提供 `playGameCardShuffleSound()` 給洗牌動畫呼叫。
- `src/components/game/animations/CardShuffleAnimation.vue` 在確認牌堆位置有效且牌數大於零後、建立 GSAP 動畫時間軸前，呼叫一次 `playGameCardShuffleSound()`。
- 主層立即播放，第二層延遲 100ms 播放；兩層各自播放 1.2 秒後停止並歸零。
- 主層使用音效設定音量的 0.25 倍，第二層使用 0.15 倍。
- 每次播放前清除上一輪計時器並重設兩層音訊，避免連續洗牌留下重疊聲音。

## 行為

1. `soundEnabled` 為 `false` 或 `soundVolume` 為零時不播放。
2. 音量依 `soundVolume` 的 0–100 設定換算至 HTML Audio 的 0–1 範圍，再分別套用主層 0.25 與第二層 0.15 增益。
3. 無效的 `deckPose`、`deckRect` 或非正數 `deckCount` 不會開始動畫，也不會播放音效。
4. 一次有效的 `play()` 呼叫只啟動一組兩層音效；一般動畫與減少動態效果模式採用相同行為。
5. 主層從 0ms 播放至 1200ms；第二層從 100ms 播放至 1300ms。
6. 新一輪洗牌開始時停止並重設仍在播放的兩層，再建立新的延遲與停止計時器。
7. 瀏覽器禁止自動播放、`Audio` 不可用或 `play()` Promise 被拒絕時，不得阻斷洗牌動畫。

## 測試

- 確認洗牌音效資產存在且非空。
- 確認牌桌音訊控制器引用洗牌音效，並使用 `soundEnabled`、`soundVolume`。
- 確認控制器建立兩個音訊實例，使用 1200ms 裁切、100ms 延遲與 0.25／0.15 增益。
- 確認重播會清除舊計時器、停止兩層並重設 `currentTime`，且播放失敗會被安全處理。
- 確認洗牌動畫在輸入驗證通過後、動畫時間軸建立前只呼叫一次音效。
- 執行牌桌音效測試、相關前端測試及正式建置。

## 範圍外

- 不加入抽牌、出牌、換牌或角色效果音。
- 不修改洗牌動畫的視覺效果或時序。
- 不調整既有牌桌背景音樂行為。
